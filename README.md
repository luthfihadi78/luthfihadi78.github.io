# luthfihadi78.github.io

Personal portfolio — [luthfihadi78.github.io](https://luthfihadi78.github.io/)

Built from scratch: no framework, no build step, no dependencies. Three files.

- `index.html` — structure and content
- `style.css` — design tokens, layout, motion
- `script.js` — typing headline, scroll reveals, count-up, canvas sparkline

Everything degrades gracefully: the page stays readable with JavaScript disabled, and
all motion is disabled under `prefers-reduced-motion`. Verified for zero horizontal
scroll at 375 / 414 / 768 / 1024 / 1440 px, WCAG AA text contrast, and 44 px minimum
touch targets.
